## ⚡ TL;DR - Los 5 Conceptos Fundamentales

1. **Arquitectura de 3 capas** (ADR-0001)
   - Application → Domain → Shared
   - Lógica de negocio SIEMPRE en Domain
   
2. **Agentic Cell Pattern** (ADR-0002)
   - 5 fases en `live()` + 6 CellLifeStages
   - D1 (DNA damage) + D2 (Immunosuppression) gobiernan el comportamiento
   
3. **Mutaciones genéticas** (ADR-0003)
   - TP53: `+/+` → `+/-` → `-/-`
   - BRCA1: NATIVO es `+/-` (NUNCA `+/+`)
   
4. **Bifásica apoptosis** (ADR-0004)
   - Intrínseca: TP53-based
   - Extrínseca: D2-based (immunosuppression)
   
5. **Tissue Manager** (ADR-0006)
   - `TissueV2`: Contenedor seguro de células
   - Captura excepciones, maneja divisiones

**⚠️ REGLA DE ORO**: Consulta `docs/adr/README.md` ANTES de arquitectura

## 📋 Las 6 ADRs (Todas Aceptadas ✅)

### ADR-0001: Arquitectura de Capas (ACEPTADA)

**¿Qué?**: Proyecto organizado en 3 capas limpias  
**¿Por qué?**: Separación de responsabilidades, testabilidad, escalabilidad  
**¿Cuándo?**: SIEMPRE que crees un nuevo archivo o refactorices  

**Estructura**:
```
┌─────────────────────────────────┐
│  Application Layer              │  ← Use cases, controllers, CLI, GUI
│  (orquestación)                 │
├─────────────────────────────────┤
│  Domain Layer                   │  ← Lógica de negocio pura
│  (Cell, Tissue, Genome, Gene)   │     (testeable, sin deps externas)
├─────────────────────────────────┤
│  Shared Layer                   │  ← Excepciones, interfaces, utilidades
│  (ICell, ports, signals)        │     (cross-cutting)
└─────────────────────────────────┘
```

**Referencia**: `docs/adr/0001-arquitectura-capas.md`  
**Implementación**: `src/application/`, `src/domain/`, `src/shared/`

### ADR-0002: Agentic Cell Pattern (ACEPTADA)

**¿Qué?**: Células son agentes autónomos con decisiones internas + 2 acumuladores (D1, D2)  
**¿Por qué?**: Refleja comportamiento biológico real, permite emergencia, simulación mas creíble  
**¿Cuándo?**: SIEMPRE que modifiques `AgenticCell_v2::live()` o `CellLifeStage`  

**Los 2 Acumuladores**:
- **D1** (DNA Damage): Acumula con edad + mutaciones. Umbral: `2.0` → PRIMER
- **D2** (Immunosuppression): Resiste apoptosis extrínseca. Umbral: `5.0` → TUMORAL

**5 Fases en `live()`**:
```cpp
void AgenticCell_v2::live() {
    // Phase 1: Check alive (baseline checks)
    
    // Phase 2: Intrinsic apoptosis (TP53-based)
    // Gatillo: TP53 -/-, baja probabilidad pero posible
    
    // Phase 3: Extrinsic apoptosis (D2-based)
    // Gatillo: D2 < 5.0 → visible al immune, puede morir
    
    // Phase 4: Neoplasm development
    // Gatillo: D1 > 2.0 + TP53 -/- → become PRIMER
    
    // Phase 5: Cytoplasm remodeling + division
    // Si neoplastic + Big Bang: divide rápido
}
```

**6 CellLifeStages**:
```cpp
enum class CellLifeStage {
    DEAD,        // !alive() - Resultado de excepciones
    BASELINE,    // TP53 +/+ & BRCA1 +/- (normal, máxima protección)
    UNSTABLE,    // TP53 +/- & BRCA1 +/- (protección débil)
    UNPROTECTED, // TP53 -/- & cualquier BRCA1 (sin protección)
    PRIMER,      // TP53 -/- + D1 > 2.0 (pre-tumoral, recibe apoptosis)
    TUMORAL      // is_neoplastic_ == true (completamente transformada)
};
```

**⚠️ REGLA CRÍTICA - BRCA1**:
- BRCA1 nativo es SIEMPRE `+/-` (heterocigoto)
- BRCA1 NUNCA es `+/+` (wild-type) en el inicio
- Razón: BRCA1 es supresor tumoral, nativo debe tener una copia mutada

**Referencia**: `docs/adr/0002-agentic-cell-pattern.md`  
**Implementación**: `src/domain/cell/AgenticCell_v2.h`

### ADR-0003: Manejo de Mutaciones (ACEPTADA)

**¿Qué?**: Sistema genético con 3 estados por gen + mutaciones probabilísticas  
**¿Por qué?**: Modelar progresión biológica realista: normal → débil → vulnerable  
**¿Cuándo?**: Cuando modifiques `Gene::live()` o probabilidades de mutación  

**Estados de Gen**:
```cpp
enum class GeneState {
    PlusPlus,    // +/+  Wild-type, protegido
    PlusMinus,   // +/-  Heterocigoto, protección parcial
    MinusMinus   // -/-  Homocigoto mutante, vulnerable
};
```

**Genes Clave**:
- **TP53** (p53, "guardián del genoma")
  - Default: `+/+` (wild-type)
  - Mutación: `+/+` → `+/-` → `-/-`
  - Efecto: Controla apoptosis intrínseca
  
- **BRCA1** (DNA repair)
  - Default: `+/-` ⚠️ (NATIVO HETEROCIGOTO)
  - Mutación: `+/-` → `-/-` (raro que mutemos)
  - Efecto: Afecta D1 (DNA damage acumulation)

**Proceso de Mutación**:
```cpp
// En Gene::live(double genomic_instability)
double threshold = mutation_threshold_ + mutation_instability_k_ * genomic_instability;
double random = noise_->nextDouble();  // [0.0, 1.0)

if (random < threshold) {
    mutate();  // +/+ → +/- o +/- → -/-
}
```

**Instabilidad Hereditaria**:
- D1 y D2 se heredan en clones (hijas reciben d1_parent_, d2_parent_)
- Cada gen tiene `mutation_instability_k_` que modula la tasa

**Referencia**: `docs/adr/0003-manejo-mutaciones.md`  
**Implementación**: `src/domain/genome/Gene.h`, `Genome.h`

### ADR-0004: Sistema de Apoptosis (ACEPTADA)

**¿Qué?**: Apoptosis en 2 fases: intrínseca (TP53) + extrínseca (D2)  
**¿Por qué?**: Refleja mecanismos biológicos reales de muerte celular  
**¿Cuándo?**: Cuando modifiques Phases 1-3 de `AgenticCell_v2::live()`  

**Phase 1: Intrinsic Apoptosis (TP53-based)**

Gatillo: Daño interno, regulado por TP53

```cpp
std::string tp53_status = genome_.getGene("TP53")->status();

if (tp53_status == "-/-") {
    // Sin TP53: apoptosis frecuente (10%)
    if (noise_->nextDouble() < 0.10) {
        throw CellDeathException("TP53 -/- intrinsic apoptosis");
    }
} else if (tp53_status == "+/-") {
    // Protección débil: apoptosis ocasional (1%)
    if (noise_->nextDouble() < 0.01) {
        throw CellDeathException("TP53 +/- intrinsic apoptosis");
    }
}
// tp53_status == "+/+": Sin apoptosis intrínseca
```

**Phase 2: Extrinsic Apoptosis (D2-based)**

Gatillo: Sistema inmune detecta célula, depende de D2 (immunosuppression)

```cpp
// Si D2 < 5.0 → visible al immune system
if (d2_immunosuppression_ < 5.0) {
    double immune_detection_prob = (5.0 - d2_immunosuppression_) * 0.02;  // Escala 0-10%
    if (noise_->nextDouble() < immune_detection_prob) {
        throw CellDeathException("Extrinsic apoptosis (immune)");
    }
}
// Si D2 >= 5.0 → "camuflada", inmune no la ve
```

**Lethality Rules**:
- BRCA1 `-/-` es letal SOLO si TP53 es `+/+` o `+/-`
- BRCA1 `-/-` NO es letal si TP53 es `-/-` (TP53 controla la letalidad)

**Referencia**: `docs/adr/0004-sistema-apoptosis.md`  
**Implementación**: `src/domain/cell/AgenticCell_v2.h` (Phases 1-3)

### ADR-0005: Big Bang Mode (ACEPTADA)

**¿Qué?**: División acelerada de neoplasias (10x tasa normal)  
**¿Por qué?**: Modelar crecimiento explosivo de tumores  
**¿Cuándo?**: Cuando modifiques divisiones o neoplasias  

**Parámetros**:
```cpp
double division_rate_;              // Normal: 0.001 (0.1%)
double neoplastic_division_rate_;   // Neoplástica: 0.01 (1%)
bool enable_big_bang_mode_;         // Flag global
```

**Lógica en Phase 5 (Cytoplasm Remodeling)**:
```cpp
double division_prob;
if (is_neoplastic_ && enable_big_bang_mode_) {
    division_prob = neoplastic_division_rate_;  // 10x más rápido
} else {
    division_prob = division_rate_;
}

if (noise_->nextDouble() < division_prob) {
    auto daughter = clone();  // Copia con herencia de D1, D2
    // Emit CellDivisionSignal
}
```

**Características de Neoplasias**:
- Inmortalidad: No mueren por apoptosis (D2 >= 5.0 + is_neoplastic_)
- Divisiones rápidas: 10x tasa normal
- Preservan D1, D2 en clones

**Referencia**: `docs/adr/0005-big-bang-mode.md`  
**Implementación**: `src/domain/cell/AgenticCell_v2.h` (Phase 4-5)

### ADR-0006: Tissue Manager (ACEPTADA)

**¿Qué?**: Contenedor seguro de células con ciclo de vida + gestión de excepciones  
**¿Por qué?**: Simular tejido como colección + orquestar muertes/divisiones  
**¿Cuándo?**: Cuando modifiques gestión de población o ciclo de simulación  

**Estructura**:
```cpp
class TissueV2 : public ports::ILoggeable {
private:
    std::vector<std::unique_ptr<ICell>> cells_;  // Ownership seguro
    ports::ILoggerPtr logger_;
    std::uint64_t tissue_id_;
};
```

**Métodos Clave**:
- `addCell(unique_ptr<ICell>)`: Agregar célula viva
- `live()`: Ejecutar ciclo de vida de TODAS las células
- `getCellsByStage(CellLifeStage)`: Filtrar por estado
- `size() const`: Contar células vivas

**Ciclo de Vida (`live()`)**:
```cpp
void TissueV2::live() {
    // 1. Iterar células
    for (auto& cell : cells_) {
        try {
            cell->live();  // Ejecutar agentic logic
        } catch (const CellDeathException& e) {
            cell = nullptr;  // Marcar como muerta
            // Logger: registrar muerte
        } catch (const CellDivisionSignal& signal) {
            addCell(signal.takeDaughter());  // Agregar hija
        }
    }
    
    // 2. Limpiar: remover nullptrs
    cells_.erase(
        std::remove_if(cells_.begin(), cells_.end(),
                      [](const auto& c) { return !c; }),
        cells_.end()
    );
}
```

**Ventajas**:
- ✅ Captura excepciones de muerte naturalmente
- ✅ ICell interface: independiente de AgenticCell_v2
- ✅ unique_ptr: memory safety automático
- ✅ Logger: tracing de eventos

**Referencia**: `docs/adr/0006-tissue-manager.md`  
**Implementación**: `src/domain/tissue/TissueV2.h`

## 🎯 Reglas de Oro 🏆

| Regla | Por qué | Referencia |
|-------|---------|-----------|
| ✅ Lógica de negocio EN Domain | Testeable, reutilizable | ADR-0001 |
| ✅ Application orquesta Domain | Separación limpia | ADR-0001 |
| ✅ Usar `unique_ptr<T>` | Memory safety | ADR-0006 |
| ✅ BRCA1 default es `+/-` | Biológicamente correcto | ADR-0003 |
| ✅ 5 fases en `live()` | Orden importa | ADR-0002 |
| ✅ Excepciones para death | Patrón natural | ADR-0004 |
| ✅ ICell interface always | No acoplar a AgenticCell_v2 | ADR-0001 |
| ❌ Raw pointers (excepto getters) | Causa memory leaks | ADR-0001 |
| ❌ Lógica de negocio en Application | Difícil de testear | ADR-0001 |
| ❌ Cambiar CellLifeStages | Rompe contrato | ADR-0002 |
| ❌ BRCA1 default `+/+` | Biológicamente incorrecto | ADR-0003 |
| ❌ Mutar genes en constructor | Deben ser inmutables en Genome | ADR-0003 |

## 🔧 Recetas: "Quiero hacer X"

### "Quiero crear una nueva clase"

1. ¿Es lógica de negocio?
   - Sí → `src/domain/nombre_modulo/ClassName.h`
   - No → Ir a 2

2. ¿Es un caso de uso / orquestación?
   - Sí → `src/application/use_cases/` o `src/application/scenarios/`
   - No → Ir a 3

3. ¿Es utilidad compartida / cross-cutting?
   - Sí → `src/shared/nombre_modulo/ClassName.h`
   - No → Revisar estructura

**Naming**:
- Clase: `ClassName`
- Header: `ClassName.h`
- Implementation: `ClassName.cpp`
- Namespace: `domain::`, `application::`, `shared::`

### "Quiero entender por qué la célula hace X"

Usa esta tabla:

| Comportamiento | Causa | Dónde mirar |
|---|---|---|
| Muere sin razón evidente | Phase 1 o 2 apoptosis | TP53 status, `alive()` |
| No se divide | D1 < 2.0 y sin TP53 -/- | Phase 4, D1 threshold |
| Se divide muy rápido | Big Bang + neoplastic | ADR-0005, division_rate_ |
| D1 crece muy rápido | BRCA1 -/-, alto mutation_instability_k_ | Gene::live() |
| No pasa a PRIMER | D1 <= 2.0 aunque TP53 -/- | Phase 4 threshold |
| Neoplasia muere | D2 < 5.0 + extrinsic apoptosis | Phase 3, D2 threshold |
